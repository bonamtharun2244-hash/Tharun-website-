# Tharun Lens — Professional Photography Sales Portfolio

A high-converting, luxury sales portfolio web application for **Tharun Lens** built with React, Vite, and Tailwind CSS.

## Features
- **Cinematic Photography Showcase:** Architectural masterpieces, nature & wilderness landscapes, cultural heritage & events, and commercial product shoots.
- **Interactive Before & After Retouching Slider:** Compares RAW sensor capture vs. Tharun Lens signature editorial color grading.
- **Dynamic Pricing & Packages:** Itemized packages with deliverables, turnaround times, and revision guarantees.
- **Interactive Live Quote Calculator:** Select services, location scope, creative add-ons, promo discounts, and generate 1-click WhatsApp quotes.
- **Client Stories & Social Proof:** Testimonials, verified client badges, and comprehensive objection handling FAQs.
- **Direct Lead Capture:** Instant WhatsApp routing (+91 91214 97402), email contact (bonamtharun2244@gmail.com), and free consultation booking modal.
- **Automated GitHub Pages CI/CD:** Ready for zero-config deployment via GitHub Actions.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

## Deploy to GitHub

### Option A: Push to GitHub Repository
```bash
# 1. Initialize git (if not already done)
git init
git add .
git commit -m "feat: complete Tharun Lens sales portfolio"

# 2. Add your GitHub remote repository (replace with your repo URL)
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git

# 3. Push code
git push -u origin main
```

### Option B: Automatic Free Live Hosting on GitHub Pages
This repository contains an automated GitHub Actions workflow in `.github/workflows/deploy.yml`.
1. Push your code to GitHub (as shown above).
2. On GitHub, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
4. GitHub will automatically build and deploy your live portfolio site!
